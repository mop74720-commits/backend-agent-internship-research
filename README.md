## 使用口径

这是一份公开材料的个人调研归档，样本统计不代表整个招聘市场。SSP、普通 offer、OC、意向和失败按原文分别记录；录用自述不等于企业独立证明。第三方项目均未运行，源码结论限于标注的静态阅读范围；个人项目设计暂缓。

本仓库按私有资料包上传，包含作者主动公开的原始简历及部分联系方式。原文件保留作者原有内容与打码。第三方简历、文章、图片及源码的权利和许可归原作者；各文件的原始来源与版本见证据清单。未为这些第三方材料添加统一开源许可。
