毕业要求：2027届
投递时间：2026年3月24日-2026年5月24日（即将截止）
岗位职责
以数据与 Token 为基石，打造工业级超级 AI Agent！
在这里，你将经历和见证：
参与构建支撑千问等大模型、百炼知识库应用的底层数据上下文供给引擎；
参与构建工业级超级AI Agent，重塑千行百业的信息系统；
探索多模态模型的微调和应用、各主流知识库实时摄取、检索等工业场景前沿方向；
体验AI + 工程  + 算法 + 产品的全栈超级个体工作方式，解决真实世界的复杂应用挑战。
【职位描述】
具体职责包括以下相关方向的一项或多项：
参与 Data + AI 全模态数据通道的设计与构建，覆盖数据库、网页、文档、音视频等多种数据源，
完成从原始数据的获取、解析、结构化到大模型与 Agent 可消费上下文的端到端交付。
参与 AI Agent 系统核心模块的设计与实现，包括意图理解、任务规划与工具调用，推动数据管道能力的服务化与智能化编排。
参与 AI 时代的知识体系建设，设计和优化知识采集、转换、切片、索引、检索等核心链路。
参与文本和视觉大模型的后训练全链路，包括高质量训练数据构建与标注、监督微调（SFT / LoRA）与对齐优化（RLHF / DPO），持续提升文档理解、版面分析等场景的模型效果。
研究和实现分布式系统、高可用架构和性能优化等关键技术，提升产品的性能、高可用性和稳定性。
岗位要求
【我们希望你】
1.计算机科学、软件工程、信息技术或相关专业的硕士或博士研究生，2027 届应届毕业生。
2.具备扎实的计算机基础知识，熟悉数据结构、算法、操作系统、计算机网络等。
3.熟练掌握至少一门编程语言（Java / Python / Golang / C++ 等），代码风格规范，擅长借助 AI Coding 工具快速完成原型开发与验证。
4.对数据库技术有浓厚的兴趣，了解关系型数据库和非关系型数据库的基本原理。熟悉云原生技术栈（Kubernetes / Serverless）或安全隔离技术（Docker / gVisor）。
5.深入理解大语言模型原理，熟悉至少一种 Agent 框架（LangGraph / ADK / LangChain 等）或核心组件（RAG / 工具调用 / 多步规划），具备 Agent 全生命周期管理（训练 / 评测 / 部署）经验。
6.具备较强的分析问题和解决问题的能力，良好的团队合作能力和沟通协作能力。

加分项：
有数据库、分布式系统、云计算或 AI 应用（如 Agent、RAG、非结构化数据处理等）相关项目经验者优先。
了解模型训练流程，熟悉数据预处理、 LoRA、Prefix Tuning 等高效微调技术、能够针对特定业务场景进行模型适配与优化，有实际模型训练或微调项目经验者优先。

【我们提供】
1.广阔的技术成长空间与职业发展平台。
2.充满活力与创新的团队氛围。
3.有竞争力的薪酬福利待遇。
4.丰富的数据、算力资源和先进的模型调优、应用平台。
5.广阔的业务场景和行业交叉创新的真实客户需求体验。
6.行业资深专家作为Mentor的指导和成熟的培养成长体系。

【工作地点】北京、杭州
