      我们在做什么
我们在做 Agent Infra。场景包括大模型强化学习训练、Agentic Agent 构建和 Agent 提效。技术方向包括沙箱运行、工具调用、记忆技能、网络治理、身份凭证和编排调度，底层涉及 Kubernetes、容器、MicroVM、网络、存储和调度。
目前支持 WorkBuddy、CodeBuddy、IMA、元宝等腾讯内部产品，也服务智谱、MiniMax 等 AI 客户的强化学习场景，承载数百万级 Sandbox。
岗位职责
参与 AgentRuntime 平台研发，支撑 WorkBuddy、ima、微信小微等腾讯核心 Agent 业务，与业务团队配合完成方案设计、研发接入、性能优化和生产落地；
围绕对话式 Agent、常驻 Agent、长任务及多 Agent 等运行模式，参与建设生命周期管理、状态持久化、暂停恢复、弹性扩缩容、工具执行、网络访问，以及 Sandbox 快速启动、快照恢复、资源隔离等 Runtime 能力；
参与核心业务生产环境中的问题排查与修复，能够跨应用、Kubernetes、容器、MicroVM、网络、存储和调度等多个层次定位并解决问题；
从业务专项中识别共性需求，协助将一次性问题沉淀为 Agent Runtime 平台能力；

【2027】届本科或研究生，计算机、软件工程、电子信息等相关专业优先。
熟练掌握 Go、Rust、C/C++ 中至少一门语言，有扎实的数据结构、算法和操作系统基础。

具备 AI Native 的工作方式，能借助 Coding Agent 学习和开发，能亲自 Build，也能独立判断 AI 生成的代码和方案是否正确。
